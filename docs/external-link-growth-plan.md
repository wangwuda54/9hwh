# External Link Growth Plan

## Goal

本阶段只建立可控的外链任务体系，不追求短期堆量，也不做垃圾外链。

## Owned Platforms

- 其他自有平台主页优先添加 9HWH 官网首页或服务总页链接。
- 视频简介优先链接对应专题页或 topic hub，而不是所有内容都回首页。
- 社媒置顶内容优先链接服务总页或核心服务页，形成稳定入口。

## Industry Content

- 围绕“海外推广准备清单”争取真实资源页或知识库引用。
- 围绕“TK / FB / Google 渠道对比”争取行业内容中的自然引用。
- 围绕“投放素材检查表”争取投放执行、素材准备、落地页检查相关内容位。

## Partner Links

- 合作页：强调能力互补、联合方案、真实合作背景。
- 访谈页：优先链接对应专题页或高相关文章。
- 资源页：优先链接服务总页、topic hub 或联系页。

## Do Not Do

- 不做垃圾外链。
- 不做 PBN。
- 不做批量目录站。
- 不做同内容多域名互链。

## Execution Notes

- 所有外链任务都应记录目标页面、落点页面、状态与备注。
- 优先自然锚文本和真实上下文，不追求硬塞关键词。
- 外链增长应配合发布节奏和内链结构，不单独暴力推进。
