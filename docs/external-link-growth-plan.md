# External Link Growth Plan

## Goal

本阶段把外链工作从“建议列表”升级为“可执行任务池”，但仍坚持人工执行、真实合作和自然上下文，不做任何操控型方案。

## Task Mix

- `owned_profile`：优先把官网首页、服务总页、专题页和联系页放进自有账号简介、置顶内容和视频说明。
- `external_article`：围绕“海外推广准备清单”“TK/FB/Google 渠道对比”“投放素材检查表”等主题，争取真实内容引用。
- `community_answer`：在真实社区讨论里补充公开资源页，回答问题优先，链接只是辅助。
- `partner_link`：面向合作页、访谈页、资源页争取自然提及，不追求生硬锚文本。
- `resource_page`：争取被行业资源页、模板页、知识库页收录，优先服务页、专题页、平台页。

## Guardrails

- 不做垃圾外链。
- 不做 PBN。
- 不做批量目录站。
- 不做自动评论。
- 不做隐藏链接。
- 不做同内容多域名互链。

## Execution Notes

- 外链节奏要跟发布节奏一致，先确保承接页、专题页、服务页准备好，再安排外链任务。
- 高风险主题优先链接到专题页、服务页、联系页等承接页，不直接追求“快速排名”式链接。
- 任务池只记录可以人工执行的动作，不记录任何灰色方案。
