# 内容审核规则

## 直接拒收

以下内容直接拒收：

- 缺少 front matter。
- content_id 不在 content_queue。
- target_url 不匹配。
- 正文过短。
- 出现保证过审、保证收益、规避审核、抗风控等禁止表达。
- 出现 `service_` 或旧 service 链接。
- 编造团队、办公室、联系方式、案例。

## 需要人工修改

以下内容需要人工修改：

- description 太短。
- 内链不足。
- 联系 CTA 不自然。
- 段落结构混乱。
- 关键词出现过多。

## 可进入 reviewed

满足以下条件可进入 `reviewed`：

- front matter 完整。
- 正文与任务包一致。
- 没有禁止表达。
- 包含服务边界。
- 至少有 2 个合理内链。
- 有联系咨询入口。

## 可进入 ready_to_publish

满足以下条件可进入 `ready_to_publish`：

- 已通过脚本审核。
- 已人工确认事实和风险表达。
- 页面标题、描述、内链和服务边界可用。
- 构建后不破坏 sitemap 和 robots。

## 不能承诺什么

不能承诺：

- 平台审核结果。
- 投放结果。
- 固定转化。
- 固定收益。
- 避开平台规则。

## 高风险词如何处理

高风险词先进入内部资产或人工审核，不直接进入公开正文、首页、导航或 sitemap。
