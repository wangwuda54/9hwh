# Rank Tracking Weekly Routine

## Cadence

- Day 7: first index check
- Day 14: first exposure check
- Day 30: trend check
- Day 60: stabilization review

## Weekly Workflow

1. Check GSC if available
2. Review only published pages
3. Update `rank_tracking_observations.json`
4. Compare impressions, clicks, and average position

## Decision Guide

- Not indexed: verify sitemap, internal links, and external discovery
- Indexed with no impressions: strengthen internal links and wait
- Impressions with no clicks: improve title and description after review
- Clicks with no inquiry: inspect CTA and page intent match

## Escalation

- Rewrite only after enough observation time
- Add internal links before expanding new content
- Add real external links before forcing major content rewrites
- Delay judgment when the page is still early in the 7 to 30 day window
