# DeepSeek 输出格式要求

## 必须按 content_id 输出

每篇文章必须独立输出，不要把多篇合并成一个文件。

## Markdown front matter

每篇文章开头必须包含：

```md
---
content_id:
title:
description:
target_url:
primary_keyword:
secondary_keywords:
status: draft_received
---
```

## 正文结构要求

正文建议包含：

- 搜索意图判断
- 适合什么项目
- 推广前准备
- 渠道建议
- 常见问题
- 服务边界
- 联系咨询

## 禁止表达

不要写：

- 保证过审
- 保证不限号
- 保证效果
- 保证转化
- 保证收益
- 绕过平台政策
- 规避审核
- 抗风控
- Cloak
- 仿牌
- 博彩
- 黑五类
- 三不限

## 服务边界要求

必须说明 9HWH 不承诺平台审核结果，不提供规避平台政策的操作，不保证投放结果。涉及平台政策、地区法规和行业限制的项目，需要在合作前确认。

## 内链要求

建议至少包含 2 个站内链接，优先链接：

- `/services/`
- `/topics/`
- `/contact/`
- 对应服务页或 topics 页

## 联系 CTA 要求

正文结尾要自然引导联系咨询，但不要夸张营销，不要承诺结果。
